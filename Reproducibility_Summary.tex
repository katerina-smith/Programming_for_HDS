# Reproducibility Summary

The starter notebook had several reproducibility problems that were addressed in this exercise. First of all, the data loading step used a hard-coded path, which was tied to the original analyst's Google Colab session and would therefore fail for any other user. Also, required libraries and versions were not documented. Additionally, the two cells for df.sample() and a bootstrap mean used unseeded randomness, which would result in obtaining different results with every execution. The mathematical notations in the descriptive-statistics section used malformed LaTeX and the notebook did not include any data validation steps. 

Each of these issues was addressed in this exercise. The step for data loading now checks for a local file before it falls
back to this project's GitHub raw URL. A setup section now lists and prints all library versions, and both randomized cells now use a shared RANDOM_SEED for reproducibility. Also the mean/standard deviation LaTeX was corrected and tied to this dataset's calculated results. The machine-learning section was removed as it was out of scope for this descriptive exercise. Additional documentation was provided in the form of markdown text in order to explain each step for an independent user. Two bivariate visualizations were also added; a justified Spearman correlation matrix, and a Mann-Whitney U test. Lastly, reproducibility was verified by restarting the kernel and running the notebook from top to bottom.
